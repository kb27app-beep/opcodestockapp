Welcome to ARYA'S Stocks Pro

Professional-grade equity research for Indian & US stocks using Yahoo Finance data.


Features:

  • 10 comprehensive analysis modules covering business model, financials, moat, valuation, risks, growth, institutional perspective, bull/bear debate, management quality, and buy/hold/avoid verdict
  • Real-time alert system with WhatsApp & Telegram integration
  • Professional charts with technical indicators
  • PDF report generation for offline reference

Quick start:

Step 1: Start the server

npm install && npm start

Or double-click start.bat

Step 2: Open in browser

Go to http://localhost:3000

Step 3: Analyze

Type a stock symbol like RELIANCE, TCS, AAPL, or MSFT and click Analyze
